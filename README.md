# Черкаси 1.2 — Графіки відключень

Простий український Android-додаток для жителів Черкащини (черга **1.2**).

## Що робить

- Автоматично перевіряє офіційний Telegram-канал **@pat_cherkasyoblenergo**
- Витягує **тільки графік для черги 1.2**
- Показує дату (наприклад «6 жовтня») і години відключення великим шрифтом
- Надсилає **пуш-сповіщення**, коли з’являється новий графік
- Зберігає історію

Людям не потрібно розбиратися з ботом — просто встановили додаток і все.

## Як встановити APK

1. Відкрий сторінку **Releases** цього репозиторію
2. Завантаж останній `app-debug.apk`
3. На телефоні дозволь встановлення з невідомих джерел
4. Встанови і **дозволь сповіщення**

## Як працює

Додаток кожні ~20 хвилин (і при відкритті) заходить на публічну сторінку каналу  
`https://t.me/s/pat_cherkasyoblenergo`, шукає повідомлення з графіками і витягує рядок `1.2 ...`.

## Збірка через GitHub Actions

При кожному пуші в `main` / `master` або вручну:

- Збирається Debug APK
- Створюється новий **GitHub Release**
- APK прикріплюється до релізу

## Технічні деталі

- Kotlin + Jetpack Compose + Material 3
- OkHttp + Jsoup (парсинг)
- Room (історія)
- WorkManager (фонова перевірка)
- Min SDK 26 (Android 8.0)
